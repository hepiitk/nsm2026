Photos for the Gallery page (gallery.html).

Easiest: open edit.html, go to the Gallery page and choose
Page -> Add photos to the gallery. The editor stores each photo here
(scaled to web size) and a small copy in the thumbs/ folder.

By hand: put the photo here and a copy about 800 px wide in thumbs/
(same file name), then add an entry to gallery.html using the TEMPLATE
in the comment above the photo grid.

Record where each photo comes from and who took it (README.md, section 6).
